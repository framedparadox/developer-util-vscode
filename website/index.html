Overview

The utility belt
you keep reaching for.

Stop pasting tokens, keys and payloads into random websites. Developer Utility Tools brings the whole kit into your editor — fast, private and consistent.

Crypto

Encrypt, hash, sign — locally.

AES-128/192/256 with CBC, CFB, CTR, OFB and ECB, five padding schemes and PBKDF2, EvpKDF or raw keys. Plus SHA-2 hashes, HMAC, TOTP, scrypt hashing, Ed25519/RSA key pairs, and a JWT debugger and signer.

Encode & decode

Base64, URL, HTML, hex, Base32/58, Unicode, punycode, gzip and data URIs.

Format & convert

JSON, XML, SQL, CSS and HTML formatters. JSON ↔ YAML ↔ XML ↔ CSV conversion.

See your data

Identifiers & time

UUID v1/v4/v7, ULID, Nano ID, Snowflake.

Generate up to 1,000 IDs at a time, with v7 values that stay ordered inside the same millisecond. Convert timestamps and explain cron expressions with the next local runs.

Network & web

Subnets, status codes, CORS, QR.

IPv4 subnets, IPv6 ULA prefixes, MAC addresses, URL and user-agent parsing, MIME types, HTTP status lookup, CORS header drafts and Wi-Fi QR codes.

Text

Regex, diff, globs and more.

Test regular expressions and glob patterns, diff text, count words and reading time, sort and dedupe lines, convert case, and generate slugs and lorem ipsum.

Privacy

What you paste stays put.

Tool input is processed in the extension host. The extension sends no analytics and no tool content to any service.

One network call

The only network operation is the explicit HTTP/HTTPS fetch in the AES tool’s optional URL input.

Secrets stay in-panel

Passwords, keys, tokens and TOTP secrets appear only in the panel that created them.

Sensible limits

Input caps (such as 10 MB for converters and Base64) keep the editor responsive and safe.

FAQ

Good questions.

Does it work offline?

Yes. Every tool runs inside VS Code’s Node runtime with bundled libraries. The sole exception is the AES tool’s optional URL input, which fetches only a URL you choose.

Does the JWT Debugger verify signatures?

No. It decodes the header and payload and checks numeric exp and nbf claims. The JWT Signer creates HS256, HS384 or HS512 tokens locally, which doesn’t imply a third party issued them.

Is the Password Hasher bcrypt-compatible?

No. It creates and checks a local scrypt hash, and the string format is not bcrypt-compatible.

Can I hide tools I don’t use?

Yes. Run Developer Utilities: Configure Sidebar to show or hide any tool and choose a layout.

What do I need installed?

Just VS Code 1.105 or later. No extra runtime is required.

Where do I report issues?

Open an issue on GitHub. Release notes live in the changelog.
