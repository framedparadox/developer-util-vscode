Privacy

Developer Utility Tools is built to keep the data you work with on your own machine.

What stays local

Tool input is processed in the VS Code extension host. The extension does not send analytics or tool content to any service. Passwords, keys, tokens and TOTP secrets are shown only in the panel that created them.

The one network operation

The only network call the extension makes is the explicit HTTP/HTTPS fetch in the AES tool’s URL input mode, which requests only a URL you choose.

This website

This site is static. It sets no cookies and has no analytics. Your light/dark preference is stored only in your browser’s local storage.
